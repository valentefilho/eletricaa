# Eletrica A 24h - Landing Page Institucional

Landing page moderna, responsiva e otimizada para conversão de serviços elétricos residenciais 24 horas em São Paulo - SP.

---

## ⚡ Sobre o Projeto

O site da **Eletrica A** foi desenvolvido para apresentar com clareza os serviços prestados, transmitir confiança por meio de depoimentos e esclarecer dúvidas com uma seção interativa de FAQ. Além disso, conta com integração direta com WhatsApp para solicitações imediatas de orçamento e emergências elétricas.

### Principais Funcionalidades:
- **Design Responsivo & Mobile-First**: Otimizado para smartphones, tablets e desktops.
- **Integração WhatsApp Lead Flow**: Formulário interativo que monta a mensagem personalizada e redireciona direto para o WhatsApp do prestador.
- **FAQ Interativo**: Acordeão dinâmico com respostas para dúvidas comuns sobre faturamento, atendimento 24h e tipos de serviços.
- **Animações Fluidas (Lazy Reveal)**: Carregamento suave dos elementos conforme a rolagem da página usando `IntersectionObserver`.
- **Links Diretos de Emergência**: Botões de chamada rápida (`tel:` e WhatsApp) para atendimento imediato.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**: Estruturação acessível e otimizada para SEO local.
- **Tailwind CSS (via CDN)**: Estilização rápida e flexível através de classes utilitárias.
- **Font Awesome 6**: Ícones vetoriais modernos.
- **JavaScript Vanilla (ES6+)**: Sem dependências pesadas, garantindo tempo de carregamento ultrarrápido.

## 🚀 Como Executar Localmente

Como a aplicação é estática e não necessita de etapas de compilação ou build:

1. Clone o repositório:
   ```bash
   git clone https://github.com/valentefilho/eletricaa.git
   cd eletricaa
   ```

2. Abra o arquivo `index.html` em qualquer navegador:
   - Dê um duplo clique no arquivo `index.html`, ou
   - Use uma extensão como o **Live Server** no VS Code.
